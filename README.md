Проект 2024 года, выполненный в рамках курса по проектированию информационных систем в Дальневосточном федеральном университете.  
Задача заключалась в разработке веб-приложения для управления складом.

Приложение позволяет выполнять поиск по товарам и формировать ключевые отчёты:
- товары на складе  
- проданные товары  
- необходимость повторного заказа  

Проект демонстрирует базовую архитектуру системы учёта поставок и может служить основой для дальнейшего расширения и перехода на промышленную СУБД.

### Stack
- Django** (основной backend-фреймворк)
- Docker** (развёртывание приложения)
- SQLite** (база данных)
- HTML / CSS — пользовательский интерфейс
